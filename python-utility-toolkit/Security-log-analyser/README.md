# Security Log Analyser

## About
A beginner Python cybersecurity project that analyses
sample login logs and reports successful and failed
login attempts.

## Features
- Counts total login attempts
- Counts successful logins
- Counts failed logins
- Identifies repeated failed attempts

## Technologies
- Python 3
- VS Code
- Git and GitHub

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run main.py.

## Example Output

Total login attempts: 5
Successful logins: 2
Failed logins: 3

## Learning Objectives
- Python loops and conditions
- Lists and strings
- Basic defensive cybersecurity
- Git and GitHub
